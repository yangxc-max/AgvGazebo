# README

This README file has been updated to reflect the implementation of the 4-layer hybrid right-of-way model derived from `scheduler_node.py`. This model features:

1. **Layer 1: Traffic Management** - Handles the assessment of traffic conditions.
2. **Layer 2: Vehicle Coordination** - Manages coordination among vehicles.
3. **Layer 3: Path Planning** - Implements algorithms for optimal path selection.
4. **Layer 4: Resource Allocation** - Allocates resources dynamically based on current conditions.

This updated architecture ensures better efficiency and responsiveness in the scheduled operations of the AGV Gazebo environment.
